# Flui Template — FastAPI

A minimal demo application built with **FastAPI** and ready to deploy on [Flui](https://flui.cloud).

This template includes:

- ⚡ FastAPI with Pydantic v2
- 🩺 `/health` endpoint
- 📦 In-memory item store with full CRUD (`/items`)
- 📖 OpenAPI 3 spec auto-generated by FastAPI (`/api/openapi`)
- 📚 Swagger UI at `/docs` (built into FastAPI)
- 🐳 Multi-stage Dockerfile (`#flui-managed`)
- 🏃 Uvicorn ASGI server

## Local development

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

App runs on http://localhost:8000

## Build with Docker

```bash
docker build -t flui-demo-fastapi .
docker run -p 8000:8000 flui-demo-fastapi
```

## Environment variables

| Variable | Default | Description |
|----------|---------|-------------|
| `APP_NAME` | `Flui Demo FastAPI` | App name |
| `APP_VERSION` | `1.0.0` | App version |
| `PORT` | `8000` | HTTP port |

## Deploy with Flui

1. Click **Use this template** on GitHub
2. Connect to Flui
3. Click **Deploy**
